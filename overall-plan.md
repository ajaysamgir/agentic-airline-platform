# AI-Native Airline Booking System

# 1. Project Goal

This project is NOT only about building an airline booking system.

The real goal is to learn:

- AI Engineering
- Agentic Workflows
- Cursor AI Development
- Multi-Agent Systems
- Microservices Architecture
- Documentation-Driven Development
- Event-Driven Architecture
- System Design
- AI-Assisted Software Development Lifecycle (SDLC)

At the end, I should be able to demonstrate:

- Requirements generated by AI
- Architecture generated by AI
- Code generated by AI
- Tests generated by AI
- Documentation generated by AI
- Multi-agent collaboration
- Distributed microservices
